# Module 4 - Uptime Information

## Goal

Display the amount of time the system has been running since it was last booted.

Example output:

- Days
- Hours
- Minutes
- Seconds

---

## Linux File Used

### /proc/uptime

A virtual file generated by the Linux kernel.

Contains:

1. Total system uptime (seconds)
2. Total idle time of all CPU cores (seconds)

Equivalent terminal command:

```bash
cat /proc/uptime
```

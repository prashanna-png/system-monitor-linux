# Module 2 - CPU Information

## Goal

Display:

- CPU Model Name
- CPU Architecture
- Physical CPU Cores
- Logical CPU Threads

---

## Linux APIs

### uname()

Returns system information through `struct utsname`.

Used to get:

- CPU Architecture (`uts.machine`)

---

## File Used

### /proc/cpuinfo

A virtual file generated by the Linux kernel.

Contains detailed information about every logical processor.

Equivalent terminal command:

```bash
cat /proc/cpuinfo
```

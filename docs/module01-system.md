# Module 1 - System Information

## Goal

Display:

- Hostname
- Username
- User ID
- Kernel Version
- OS Version

---

## Linux APIs

gethostname()

- Returns hostname

getuid()

- Returns current user's UID

getpwuid()

- Converts UID to username

uname()

- Returns kernel/system information

---

## File I/O

fopen()

- Opens a file

fgets()

- Reads one line

fclose()

- Closes the file

---

## String Functions

strncmp()

- Compare first n characters

strchr()

- Find first occurrence of a character

strrchr()

- Find last occurrence of a character

---

## Pointer Notes

p -> address
\*p -> value at address
&x -> address of x
